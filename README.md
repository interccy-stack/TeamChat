================================================================================
  五、关键设计决策
================================================================================

  后端:
    • Pydantic 模型必须模块级别  — 嵌套在函数内 → UnboundLocalError
    • Form() 与 JSON 不兼容      — 前端 JSON body 必须用 Pydantic 接收
    • httpx trust_env=False      — QwenPaw Desktop 有 Privoxy 代理
    • SessionStore 文件级 JSON   — data/*.json, 内存缓存 + 同步写盘
    • MAX_HISTORY = 500          — 单会话最多保留 500 条消息
    • /sessions 返回精简摘要     — 不含 history/host_steps, 响应体缩减 95%
    • /session/{id} 返回完整数据 — 加载历史时获取全部消息
    • pinned 强制 bool(s.get("pinned")) — 防 mixed type TypeError
    • agent_id or fallback        — config.json null 时用 "cloud-orchestrator"
    • config 路径双级 os.path.dirname — 修复串串频道重启后状态丢失 (v4.1.0)

  AI群聊 (v5.1.3):
    • 模块预加载机制            — 启动时预导入 ai_group_chat，避免运行时延迟导入失败
    • sys.path 动态保障         — 插件隔离环境下手动添加插件目录到 sys.path
    • 错误缓存机制              — _ai_engine_error 缓存初始化失败原因，避免重复报错
    • 5个常驻智能体             — ali、executor、qa、master、verifier 常驻聊天室
    • @提及解析                 — 正则 /@(\w+)/ 解析消息中的提及，指定特定智能体回复
    • DataStore 持久化          — ai_chat_data.json 存储消息历史，3秒轮询实时同步
    • 小红书风格 UI             — 圆角卡片、紫色渐变标签、悬停放大特效

  前端:
    • snap ref 防闭包过期        — saveTab() 读 useRef 不读闭包
    • activeTabRef 实时 tabId    — unmount cleanup 用 ref 获最新值
    • syncActiveTab 每回调落地   — 4 个写入点 (普通/脑暴每轮/脑暴完成/汇总)
    • _abortRef 桥接 IIFE 作用域 — 解决 apiPostAbort 访问不到组件 abortRf
    • stopRef 脑暴防穿透         — round() 入口检查 stopRef.current
    • localStorage 会话缓存优先  — 离线下仍可浏览历史列表
    • 安全锁 busyRef 三层防御    — UI 禁用 + 橙条警告 + send 拦截
    • 圆桌 canvas 永远不 unmount — position:fixed 常驻，仅 CSS 切换位置
    • 广告 localStorage 一次性   — teamchat_ad_shown 永久标记
    • getApiUrl 动态端口解析     — 下载链接跨版本/端口自动适配

  串串频道 (v4.1.0):
    • 视图切换而非路由            — QwenPaw registerRoutes 不支持 hash 导航
    • wxView state 控制           — false→TeamChatPage, true→WeChatPage
    • 与游戏平台 Lobby↔Room 同模式 — 不依赖 Router，React 原生状态切换
    • 串串频道使用 QwenPaw 内置   — 通过 /api/channels/wechat/ 路由
    • cloud-orchestrator 负责主持 — SOUL.md + PROFILE.md 写入主持人规则
    • 举一反三全平台              — 飞书/钉钉/QQ/Telegram/Discord 同原理

  轻音乐引擎 (v4.1.0):
    • volRf 音量 ref              — 同步 localStorage teamchat_music_vol
    • Slider 0.1-1.0             — tooltip 显示百分比
    • gain.gain 动态应用音量      — 替代硬编码 0.25
    • Popover 内部 ⏹ 停止按钮    — 红色 danger，播放中才出现
    • ▶ 正在播放: [曲名]         — 红色加粗居中指示条

  localStorage 键名汇总:
    teamchat_tabs, teamchat_last_session,
    teamchat_sessions_cache, teamchat_shortcut_hint,
    teamchat_custom_song, teamchat_music_vol,    ← v4.1.0 新增
    teamchat_ad_shown
