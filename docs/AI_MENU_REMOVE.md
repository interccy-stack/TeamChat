# AI副驾菜单删除说明

## 修改内容

删除了AI邮箱主菜单中的"AI副驾"独立菜单项。

## 修改前
AI邮箱主菜单有3个选项：
- 📧 传统邮箱
- 🏠 蜂巢邮箱  
- 🤖 AI副驾（已删除）

## 修改后
AI邮箱主菜单有2个选项：
- 📧 传统邮箱
- 🏠 蜂巢邮箱

## 为什么删除

AI副驾功能已改为**全局浮动面板**，通过右下角的 🤖 按钮在所有AI邮箱页面访问，无需单独的菜单项。

## 访问方式

1. 进入AI邮箱功能（传统邮箱或蜂巢邮箱）
2. 点击右下角的 🤖 浮动按钮
3. AI副驾面板从右侧滑出

## 文件修改

- 文件：`frontend/dist/index.js`
- 位置：AI邮箱主视图（aimailMode === "main"）
- 删除代码：AI副驾菜单项的div元素

## 验证

```bash
# 语法检查
node --check index.js
# 结果: 无错误
```

- ✅ AI副驾浮动按钮（🤖）
- ✅ AI副驾全局面板
- ✅ 智能优化功能
