## 📦 安装步骤

### 1. 获取Token
```
1. 打开TeamChat插件
2. 点击AI分身面板
3. 点击"🔑 生成Token"按钮
4. 复制生成的Token（32位字符）
```

### 2. 安装Chrome扩展
```
1. 打开 Chrome 浏览器
2. 访问 chrome://extensions/
3. 开启右上角"开发者模式"
4. 点击"加载已解压的扩展"
5. 选择文件夹：
   C:\Users\lenovo\.copaw\plugins\team_chat\extension
6. 安装成功！🎉
```

### 3. 配置Token
```
1. 点击浏览器工具栏的 🤖 图标
2. 粘贴刚才复制的Token
3. 点击"保存Token"
4. 显示绿色"保存成功"即可
```

## 🚀 使用方法

### 唤起AI分身
```
1. 打开任意网页
2. 右下角出现一闪一闪的 🤖 按钮
3. 点击按钮展开AI分身面板
4. 输入消息，AI立即回复！
```

### 关闭面板
```
- 点击面板右上角的 ✕ 按钮
- 按键盘 ESC 键
- 点击面板外部区域
```

### 调整位置
```
- 按住 🤖 按钮拖动
- 松开自动保存位置
- 下次打开自动恢复
```

## 🔧 技术原理

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Chrome扩展  │────▶│ Background  │────▶│  localhost  │
│  (content.js)│     │  (background.js)│  │  :8088     │
└─────────────┘     └─────────────┘     └─────────────┘
       │                                           │
       │              跨域通信                       │
       │◀──────────────────────────────────────────┘
       │
┌─────────────┐
│   AI分身    │
│  浮动按钮   │
└─────────────┘
```

**核心机制：**
- Background Script 处理跨域请求
- Content Script 注入到所有网页
- 消息通道实现安全通信

## 🐛 故障排除

### 按钮不显示
```
1. 刷新网页
2. 检查扩展是否启用
3. 按F12查看Console错误
```

### 无法连接
```
1. 确认QwenPaw已运行
2. 检查Token是否正确
3. 重新保存Token
```

### 位置不保存
```
1. 确保已拖拽到新位置
2. 检查浏览器存储权限
```
