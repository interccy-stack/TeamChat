## 一、产品简介

AI PRO 是一款浏览器扩展，让你在任何网页随时召唤 AI 助手。支持多智能体切换、智能页面感知、语音交互、会话管理等功能。

### 支持浏览器

| 浏览器 | 说明 |
|--------|------|
| **Microsoft Edge** ⭐ | 国内首选。基于 Chromium 内核，原生支持 Chrome 扩展，无需翻墙即可使用。Windows 10/11 自带。 |
| Google Chrome | 功能完全支持，需能访问 Chrome 网上应用店（国内网络可能受限）。 |
| 其他 Chromium 浏览器 | 360极速、QQ浏览器、Brave、Opera 等均可加载。 |

> 💡 **国内用户推荐使用 Microsoft Edge**。Edge 与 Chrome 共享同一内核（Chromium），扩展完全兼容，且在国内网络环境下更新、同步更稳定。

### 核心特色
- 🤖 **多智能体支持** — 常用智能体 + 全部智能体分组切换
- 🌐 **智能页面感知** — 自动识别当前页面类型，提供相关建议
- 🎤 **语音交互** — 语音输入 + AI 语音朗读回复
- 💬 **会话管理** — 自动保存最多10条会话，按时间线彩色圆点显示
- 🌙 **暗黑模式** — 一键切换，护眼舒适
- 📊 **数据抓取** — 一键提取页面内容发送给AI分析

## 二、安装指南

### 2.1 推荐：Microsoft Edge（国内首选 🇨🇳）

Edge 是 Windows 10/11 自带浏览器，与 Chrome 使用同一 Chromium 内核，**原生支持 Chrome 扩展**，无需安装额外浏览器。

1. **下载并解压**
   - 将 `AI-PRO-v5.0.18-full.zip` 解压到任意文件夹（如 `C:\AI_PRO\`）

2. **打开扩展管理页面**
   - 地址栏输入 `edge://extensions/` 并回车
   - 左侧边栏或右上角开启「**开发人员模式**」（Developer mode）

3. **加载扩展**
   - 点击「**加载解压缩的扩展**」
   - 选择解压后的 `AI_PRO` 文件夹
   - 看到 🤖 图标即安装成功

4. **固定到工具栏**
   - 点击地址栏右侧的 🧩 扩展图标
   - 找到「AI PRO」→ 点击 👁️ 图标固定
   - 工具栏上出现 🤖 图标，随时点击使用

### 2.2 Google Chrome 安装

1. **下载并解压**同上
2. 地址栏输入 `chrome://extensions/` → 右上角开启「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」→ 选择 `AI_PRO` 文件夹
4. 固定扩展图标到工具栏

### 2.3 其他 Chromium 浏览器

360极速浏览器、QQ浏览器、Brave、Opera 等步骤类似，扩展管理页面地址为各浏览器的 `xxx://extensions/`。

### 2.4 首次使用

1. 确保 QwenPaw 服务在运行（默认 `http://localhost:8088`）
2. 点击浏览器工具栏的 🤖 扩展图标
3. 弹窗会**自动尝试获取 Token**，成功后显示「已激活」
4. 也可**手动粘贴 Token** → 点击「✨ 激活」
5. 在任意网页双击右下角浮动按钮即可使用

## 四、功能详解

### 4.1 智能体切换

1. 点击头部「Agent 选择器」下拉框
2. 选择「⭐ 常用」或「📋 全部」分组
3. 切换后自动应用新智能体

### 4.2 工具栏按钮

| 按钮 | 功能 |
|:----:|:-----|
| 🌙 | 暗黑模式 |
| 📸 | 截图识图 |
| 💾 | 导出聊天 |
| 📋 | AI总结 |
| 📊 | 数据抓取 |
| 📋 | 复制内容 |
| 📝 | 自动填表 |
| 👤 | 语音切换 |

### 4.3 语音功能

**语音输入**: 点击 🎤 按钮说话
**语音输出**: AI 自动朗读，点击 🔊 重播

### 4.4 快捷指令

输入 `/` 显示指令列表：
- `/summary` — 总结页面
- `/translate` — 翻译内容
- `/explain` — 解释代码
- `/new` — 新建会话

### 4.5 双模式切换

点击 📌 按钮切换：
- **浮动模式** — 自由拖拽
- **侧边栏模式** — 固定右侧

## 五、会话管理

### 5.1 自动保存

## 七、常见问题

### Q1: 显示「连接失败」？
1. 确认 TeamChat 服务已启动
2. 检查 `localhost:8088` 可访问
3. 点击「重新连接」

### Q2: 浮动按钮不显示？
1. 刷新网页
2. 检查扩展已启用
3. 重启浏览器

### Q3: 语音识别无效？
- 使用 Chrome 浏览器
- 检查麦克风权限
- 使用键盘输入代替
